🌱 PlantCare – Plant Disease Information System

About the Project

PlantCare is a simple web-based application that helps users learn about common plant diseases, identify possible issues based on selected symptoms, and understand basic prevention methods.

Features

* 🌿 Plant disease information
* 🔍 Symptom-based disease suggestions
* 🪴 Disease search functionality
* 💡 Plant disease prevention tips
* 🔐 Demo login page
* 📱 Responsive website design

Technologies Used

* HTML
* CSS
* JavaScript

Project Files

* index.html – Main webpage
* login.html – Demo login page
* style.css – Website styling
* script.js – Disease information and symptom-checking logic

How to Run

1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Open index.html using Live Server or a web browser.

Important Note

This project uses sample disease information and symptom-matching logic for educational purposes. It does not provide a confirmed plant disease diagnosis. The login page is a demonstration and does not implement real authentication.

Future Improvements

* Add an AI-based plant disease detection model.
* Include more plant species and diseases.
* Improve the symptom-checking process.
